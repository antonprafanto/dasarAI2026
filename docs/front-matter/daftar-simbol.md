# Daftar Simbol Matematika

---

Berikut adalah daftar simbol matematika yang digunakan dalam buku ini. Gunakan halaman ini sebagai referensi cepat ketika menemukan simbol yang tidak familiar.

## 🔢 Simbol Dasar

| Simbol    | Nama                         | Arti                                | Contoh             |
| --------- | ---------------------------- | ----------------------------------- | ------------------ |
| $=$       | Sama dengan                  | Kedua sisi memiliki nilai yang sama | $2 + 3 = 5$        |
| $\neq$    | Tidak sama dengan            | Kedua sisi memiliki nilai berbeda   | $2 \neq 3$         |
| $\approx$ | Kira-kira sama dengan        | Nilai yang hampir sama              | $\pi \approx 3.14$ |
| $<$       | Kurang dari                  | Nilai kiri lebih kecil              | $2 < 5$            |
| $>$       | Lebih dari                   | Nilai kiri lebih besar              | $5 > 2$            |
| $\leq$    | Kurang dari atau sama dengan | Nilai kiri lebih kecil atau sama    | $x \leq 10$        |
| $\geq$    | Lebih dari atau sama dengan  | Nilai kiri lebih besar atau sama    | $x \geq 0$         |

## 📊 Simbol Statistika & Probabilitas

| Simbol     | Nama           | Arti                          | Contoh                                 |
| ---------- | -------------- | ----------------------------- | -------------------------------------- | --------------- | ---------------- |
| $P(A)$     | Probabilitas A | Peluang terjadinya kejadian A | $P(\text{hujan}) = 0.3$                |
| $P(A       | B)$            | Probabilitas bersyarat        | Peluang A terjadi jika B sudah terjadi | $P(\text{hujan} | \text{mendung})$ |
| $\mu$      | Mu             | Rata-rata (mean) populasi     | $\mu = 75$                             |
| $\bar{x}$  | X bar          | Rata-rata sampel              | $\bar{x} = 72.5$                       |
| $\sigma$   | Sigma          | Standar deviasi populasi      | $\sigma = 5$                           |
| $\sigma^2$ | Sigma kuadrat  | Varians                       | $\sigma^2 = 25$                        |
| $\sum$     | Sigma besar    | Penjumlahan                   | $\sum_{i=1}^{n} x_i$                   |
| $\prod$    | Pi besar       | Perkalian                     | $\prod_{i=1}^{n} x_i$                  |

## 🧮 Simbol Aljabar Linear

| Simbol                      | Nama              | Arti                              | Contoh                                            |
| --------------------------- | ----------------- | --------------------------------- | ------------------------------------------------- |
| $\vec{x}$ atau $\mathbf{x}$ | Vektor x          | Kumpulan nilai dalam satu dimensi | $\mathbf{x} = [1, 2, 3]$                          |
| $\mathbf{X}$                | Matriks X         | Kumpulan nilai dalam dua dimensi  | Tabel data                                        |
| $\mathbf{X}^T$              | Transpose         | Menukar baris menjadi kolom       | $[1, 2]^T = \begin{bmatrix} 1 \\ 2 \end{bmatrix}$ |
| $\mathbf{X}^{-1}$           | Invers            | Matriks kebalikan                 | $\mathbf{A}\mathbf{A}^{-1} = \mathbf{I}$          |
| $\mathbf{I}$                | Matriks identitas | Matriks dengan diagonal 1         | $\begin{bmatrix} 1 & 0 \\ 0 & 1 \end{bmatrix}$    |
| $\cdot$                     | Dot product       | Perkalian titik antar vektor      | $\mathbf{a} \cdot \mathbf{b}$                     |
| $\|\mathbf{x}\|$            | Norm              | Panjang/magnitudo vektor          | $\|[3, 4]\| = 5$                                  |

## 🔄 Simbol Kalkulus

| Simbol                        | Nama            | Arti                           | Contoh                                                                      |
| ----------------------------- | --------------- | ------------------------------ | --------------------------------------------------------------------------- |
| $\frac{d}{dx}$                | Turunan         | Laju perubahan terhadap x      | $\frac{d}{dx}(x^2) = 2x$                                                    |
| $\frac{\partial}{\partial x}$ | Turunan parsial | Turunan terhadap satu variabel | $\frac{\partial f}{\partial x}$                                             |
| $\nabla$                      | Nabla/Gradien   | Vektor turunan parsial         | $\nabla f = [\frac{\partial f}{\partial x}, \frac{\partial f}{\partial y}]$ |
| $\int$                        | Integral        | Luas di bawah kurva            | $\int_0^1 x \, dx$                                                          |
| $\Delta$                      | Delta           | Perubahan                      | $\Delta x = x_2 - x_1$                                                      |
| $\lim$                        | Limit           | Nilai saat mendekati           | $\lim_{x \to 0} \frac{\sin x}{x} = 1$                                       |

## 🔣 Simbol Logika

| Simbol            | Nama        | Arti                   | Contoh                     |
| ----------------- | ----------- | ---------------------- | -------------------------- |
| $\land$           | AND         | Dan (konjungsi)        | $A \land B$                |
| $\lor$            | OR          | Atau (disjungsi)       | $A \lor B$                 |
| $\neg$            | NOT         | Negasi                 | $\neg A$                   |
| $\Rightarrow$     | Implikasi   | Jika... maka...        | $A \Rightarrow B$          |
| $\Leftrightarrow$ | Biimplikasi | Jika dan hanya jika    | $A \Leftrightarrow B$      |
| $\forall$         | Untuk semua | Universal quantifier   | $\forall x \in \mathbb{R}$ |
| $\exists$         | Ada         | Existential quantifier | $\exists x$                |

## 📐 Simbol Himpunan

| Simbol       | Nama              | Arti                   | Contoh                         |
| ------------ | ----------------- | ---------------------- | ------------------------------ |
| $\in$        | Elemen dari       | Anggota himpunan       | $3 \in \{1, 2, 3\}$            |
| $\notin$     | Bukan elemen dari | Bukan anggota          | $4 \notin \{1, 2, 3\}$         |
| $\subset$    | Subset            | Himpunan bagian        | $\{1, 2\} \subset \{1, 2, 3\}$ |
| $\cup$       | Union             | Gabungan               | $A \cup B$                     |
| $\cap$       | Intersection      | Irisan                 | $A \cap B$                     |
| $\emptyset$  | Himpunan kosong   | Himpunan tanpa anggota | $\emptyset$                    |
| $\mathbb{R}$ | Real numbers      | Bilangan real          | $x \in \mathbb{R}$             |
| $\mathbb{N}$ | Natural numbers   | Bilangan asli          | $\{1, 2, 3, ...\}$             |
